# DockPilot browser demo

This folder is a self-contained static build for GitHub Pages. Upload the **contents of this folder** as your Pages artifact (or set this folder as the Pages source). It works from a repository project URL such as `https://OWNER.github.io/REPOSITORY/` because its built asset links are relative.

Open the page and choose **Open demo dashboard**. The mock service creates a demo operator and example credentials, audit events, and an approval. The AI credential, audit log, approval inbox, and sign-out interactions run locally in the browser and persist in that browser's local storage.

This is a UI demo only—not a DockPilot server. It makes no real API calls and cannot control Docker. Use only fake details; do not enter a real password, token, or private information. Use **Sign out** to return to the sign-in screen. Clear this site's local storage to reset the demo.
